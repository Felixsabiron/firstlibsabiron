# Donnees des elus municipaux

Ce jeu de donnees contient les informations sur les conseillers
municipaux.

## Usage

``` r
elus_conseillers_municipaux_cm
```

## Format

Un data frame avec 9753 lignes et 16 colonnes :

- Code du departement:

  Code numerique du departement

- Libelle du departement:

  Nom du departement

- Code de la collectivite:

  Code unique de la collectivite

- ...:

  Autres colonnes
