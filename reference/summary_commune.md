# Resume pour les objets de classe "commune"

Cette fonction genere un resume pour les objets de classe `commune`.
Elle affiche le nom de la commune, le nombre total d'elus et la
repartition professionnelle.

## Usage

``` r
summary_commune(obj, ...)
```

## Arguments

- obj:

  Un objet de classe `commune`.

- ...:

  Arguments supplementaires (non utilises).

## Value

Un resume des informations de la commune sous forme de liste.
